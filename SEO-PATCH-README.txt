SEO PATCH — TulisKetik.id

Domain rekomendasi:
tulisketik.id

Catatan:
- Hasil pencarian web tidak menemukan situs aktif di tulisketik.id pada saat pengecekan,
  tetapi status REGISTRASI domain tetap harus dikonfirmasi di registrar sebelum membeli.
- Jangan pasang file CNAME sebelum domain benar-benar dibeli dan DNS sudah diarahkan.

Struktur URL baru:
/
jasa-tulis-tangan/
jasa-ketik/
pdf-ke-word/
foto-ke-word/
transkripsi/
penyedia/
jasa/tulis-tangan-rina/
jasa/ketik-word-andri/
jasa/transkripsi-sari/

Perubahan SEO utama:
1. URL bersih tanpa .html pada landing page utama.
2. Setiap intent pencarian punya halaman sendiri.
3. H1, title, meta description unik.
4. Canonical memakai https://tulisketik.id/.
5. Open Graph dan Twitter Card konsisten.
6. WebSite, CollectionPage, dan Service schema.
7. Listing utama ditulis langsung di HTML agar konten inti tidak bergantung pada JavaScript.
8. Internal linking antar kategori dan detail jasa.
9. robots.txt + sitemap.xml.
10. 404 diberi noindex.

Cara memasang:
- Timpa index.html, robots.txt, sitemap.xml, 404.html, dan assets/app.js.
- Tambahkan folder baru yang ada di patch.
- Folder/assets lain seperti style.css, logo.png, dan og-image.png tetap gunakan file lama.
- Setelah domain dibeli, arahkan DNS ke GitHub Pages lalu set Custom Domain ke tulisketik.id.
